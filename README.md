# jogo-luta

Jogo de luta 2D no navegador com os amigos do grupo como personagens.

**Jogar:** https://thomasalbuquerque.github.io/jogo-luta/

## Rodando localmente

Requer Node 22+ e pnpm.

```bash
pnpm install
pnpm dev
```

Regras do jogo em [`docs/GDD.md`](docs/GDD.md), plano em [`docs/ROADMAP.md`](docs/ROADMAP.md).
